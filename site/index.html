Repository

This page loads the production bundle query-play.min.js from the same folder. It uses a small sample OpenAPI document (sample-openapi.json).

Notes

  • The component is shipped as a single-file ES module-compatible bundle in query-play.min.js.
  • If you want to use a remote OpenAPI URL, set api="https://example.com/openapi.json" on the element.
  • For production, serve these static files from any static host (Netlify, Vercel, S3, Azure Static Web Apps, etc.).
